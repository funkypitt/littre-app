Le dictionnaire Littré

Dictionnaire Littré complet, gratuit et hors-ligne.

Overview

Application Android offline du Dictionnaire de la langue française d'Émile Littré (Hachette, 1873–1874), basée sur les données XML libres de François Gannaz (xmlittre). 78 599 entrées avec définitions, étymologies et citations, consultables sans connexion.

Features

  • 78 599 entrées, consultables hors ligne
  • Recherche par préfixe (autocomplétion instantanée)
  • Recherche plein texte dans les définitions (SQLite FTS5)
  • Mot du jour
  • Favoris et historique de consultation
  • Renvois croisés cliquables entre articles
  • Mode sombre automatique
  • Typographie soignée (Merriweather)
  • Aucune connexion internet requise

Build & install

# 1. Préparer la base de données
cd tools/
git clone https://bitbucket.org/Mytskine/xmlittre-data.git
python3 convert_littre.py xmlittre-data -o ../assets/littre.db

# 2. Compiler
flutter pub get
flutter build apk
